# LegCord Bypass (LegFork)

Кастомный Discord-клиент на базе [Legcord](https://github.com/Legcord/Legcord) с **автоматическим обходом DPI-блокировок** через прокси — для Windows, в первую очередь для пользователей из РФ.

Запустил — и если Discord недоступен напрямую, встроенная «прокси-машина» сама находит рабочий прокси, проверяет его и подключается. Весь процесс виден на стартовом экране в реальном времени: от «Ищем рабочий прокси…» до «Прокси работает».

## Возможности

- **Автоматический обход блокировок (Windows)**

  Без zapret и внешних движков: встроенные списки прокси, живая проверка каждого кандидата (CONNECT-пробу до Discord), бесшовный переключатель. Если Discord снова «ожил» напрямую — клиент это увидит и вернётся к прямому подключению.

- **Наглядный стартовый экран**

  Тёмный экран-интро с анимацией, живой строкой статуса («Ищем прокси…», «Проверяем прокси 1–5…», «Подключаемся…») и понятными ошибками. При успехе — оверлей «РКН был отъебан».

- **Раздел «Настройка прокси»**

  В настройках клиента: свой список прокси, авторежим, ручной прокси `host:port` или `socks5://…`, порог скорости и кнопка принудительной смены.

- **Маяк LegCord-пользователей**

  Клиент по умолчанию транслирует «маяк»: другие пользователи LegCord/Bypass видят друг друга — у ника появляется маленькая градиентная точка (в сообщениях, списках участников, ЛС). При открытии настроек в углу показывается живой счётчик **«LegCord online»**. Отключить маяк: `window.legcordUsersBeacon(false)` в консоли Discord.

- **Автономный клиент**

  Не требует установленного Discord: отдельное приложение на Electron.

- **Моды и темы**

  Встроенная поддержка [Vencord](https://github.com/Vendicated/Vencord) и [Shelter](https://github.com/uwu/shelter), импорт BetterDiscord-тем, Rich Presence из коробки ([arRPC](https://arrpc.openasar.dev)), блокировка трекеров Discord.

## Установка (Windows)

1. Скачай установщик **`Legcord-<версия>-win-x64.exe`** со страницы [Releases](../../releases).
2. Запусти и установи.
3. Готово — при первом запуске можно сразу проверить работу обхода.

> Портативный режим: положи папку `legcord-data` рядом с исполняемым файлом — все данные будут храниться в ней.

## Сборка из исходников

Нужны [Node.js v26+](https://nodejs.dev) и [pnpm](https://pnpm.io):

```sh
git clone https://github.com/Fatzik/legcord-bypass.git
cd legcord-bypass
pnpm install
pnpm run build      # сборка
pnpm run package    # упаковка приложения (или packageQuick для папки без установщика)
```

## Частые вопросы

**Забанят ли за использование?**

Ты нарушаешь [ToS Discord](https://discord.com/terms#software-in-discord%E2%80%99s-services), но массовых банов за Legcord или входящие моды не было.

**Где настройки?**

Открой настройки Discord — появится пункт **Legcord Settings** (белая иконка). Также настройки доступны через иконку в трее.

**Почему Discord недоступен напрямую?**

Это штатная работа обхода: если `discord.com` режется провайдером, клиент автоматически ищет рабочий прокси. Если прокси не найден — покажет ошибку с полем для ручного ввода (например, `72.56.38.111:10135`).
